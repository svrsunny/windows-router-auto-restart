# Android companion app

Part of the project since 2.2.0. It appears on the phone as **Router Auto Restart**. It alerts you
when your router is reachable but the internet is down, and restarts the router with one tap, from
the app or straight from the alert.

The full guide (install, setup, how it works, permissions, security, building) is in
[docs/android.md](../docs/android.md).

```
app/AndroidManifest.xml     manifest (Android 8.0+, target API 34)
app/res/                    launcher and notification icons (generated by tools/make_icons.py)
app/src/                    Java sources (no libraries)
tests/                      PC-side tests: protocol parity with the Windows adapter, alert logic, fake router
tools/fetch_toolchain.sh    downloads and prepares the pinned build toolchain
tools/build.sh              builds and signs the APK without Android Studio or Gradle
tools/make_icons.py         regenerates the icons from the project logo
```
