# Android companion app

Part of the project since 2.2.0. It appears on the phone as **Router Auto Restart**. It alerts you
when your router is reachable but the internet is down, and restarts the router with one tap, from
the app or straight from the alert.

The full guide (install, setup, how it works, permissions, security, building) is in
[docs/android.md](../docs/android.md).

Build it with `gradlew assembleRelease` (or open this folder in Android Studio). See
[Building from source](../docs/android.md#building-from-source).

```
settings.gradle, build.gradle    Gradle project (Android Gradle Plugin 9.4, no library dependencies)
gradlew, gradlew.bat, gradle/    Gradle wrapper (download checked against its SHA-256)
app/build.gradle                 app id, SDK levels, version, release signing
app/AndroidManifest.xml          permissions and components (Android 8.0+, target API 34)
app/lint.xml                     the lint warnings that are intentional
app/res/                         icons (generated by tools/make_icons.py), backup rules
app/src/                         Java sources
tests/                           PC-side tests: protocol parity with the Windows adapter, alert logic, fake router
tools/make_icons.py              regenerates the icons from the project logo
```
